# S.MOT International Beauty House — версия 19

## Что внутри
- `index.html` — весь сайт одним файлом. Уже подключён к вашей базе Supabase (проект yoheyfsgewikjqbficrr). Netlify публикует именно его.
- `source/` — исходники по частям: тексты на 6 языках (`i18n.js`), работа с базой (`data.js`), экраны (`app.js`), стиль (`styles.css`), слои версий (`v3.js` … `v20.js`).
- `ios-app/` — приложение для iPhone (Capacitor). Берёт `index.html` из корня, поэтому сайт и приложение всегда одинаковые.
- `codemagic.yaml` — сборка приложения для App Store в Codemagic (workflow «S.MOT Academy iOS»).

## Новое в версии 19 — бесплатное открытие
- Пока включён режим **«Бесплатное открытие»**, любой опубликованный курс можно пройти бесплатно. На главной — золотая полоса-приглашение.
- Выключается в Кабинете → Админ, когда подключим оплаты. Кто уже записался, сохраняет доступ.

## Новое в версии 18 — студия мастера
- **Моя студия** (Кабинет → Моя студия): сколько работ ждут проверки и как давно, вопросы без ответа, ученики, курсы.
- **Быстрая проверка:** очередь от самой старой работы, **быстрые фразы** для отзыва (свои, сохраняются) и кнопка **«Сохранить и дальше»**.
- **Вопросы мастеру под каждым уроком** (с таймкодом). Мастер отвечает в студии или прямо под уроком, ученица получает уведомление, ответ видят все ученики курса.
- **Мои ученики:** прогресс, последний вход, средняя оценка. Кнопка **«Напомнить»** для тех, кто давно не заходил, и **сообщение всем ученикам курса**.
- **Порядок уроков** стрелками ↑↓ и **загрузка нескольких видео сразу** — каждый файл становится уроком.

## Новое в версии 17 — инструменты ученицы
- **Продолжить просмотр** — платформа помнит, где ты остановилась, на любом устройстве.

- **«Мой рост»** — график оценок мастера и рост по каждому критерию.
- **Портфолио «до/после»** (Кабинет → Портфолио, публичная ссылка `#portfolio-…`) — оценка подтягивается из проверки мастера, подделать нельзя.

## Как запустить
1. Зайдите на netlify.com → Add new site → Deploy manually.
2. Перетащите папку с `index.html`. Через минуту сайт будет работать по ссылке.
3. В Supabase → Authentication → URL Configuration добавьте адрес сайта в Site URL и Redirect URLs (для подтверждения почты и сброса пароля).

## Как назначить себя администратором
После регистрации на сайте выполните в Supabase → SQL Editor:
```sql
insert into public.user_roles (user_id, role)
select id, 'admin' from auth.users where email = 'ВАША_ПОЧТА';
```

- База ускорена: добавлены 30 индексов, удалён дубль.

## Как проверить весь цикл на живом сайте
1. Зарегистрируйтесь, назначьте себя администратором (SQL выше).
2. Создайте второй аккаунт для теста ученика.
3. Себе включите роль «Преподаватель», загрузите диплом и подтвердите его как администратор.
4. Создайте курс, загрузите урок с видео, отправьте курс на модерацию и опубликуйте.
5. Запишите тестового ученика на курс (Пользователи → Записать на курс).
6. Войдите как ученик: посмотрите урок, отправьте работу, напишите преподавателю.
7. Войдите как преподаватель: поставьте оценку и ответьте на сообщение.
8. Отметьте все уроки пройденными — сертификат выдастся автоматически; проверьте его номер на странице проверки.
